# Vibeduck releases 🦆🕶️

Downloads and update feed for **Vibeduck**, Agent D's Mac app that smuggles Chrome extensions out of Chromium City and into the Safari Zone.

- **Download:** grab `Vibeduck.dmg` from the [latest release](https://github.com/SmithWinter/Vibeduck-releases/releases/latest), open it and drag Vibeduck into Applications.
- **Updates:** Vibeduck checks `appcast.xml` in this repo through Sparkle, so installed copies update themselves.

The source code lives in a private repository. This repo only carries the signed builds.
